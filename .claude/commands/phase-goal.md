指定されたフェーズの /goal 文面を組み立てて出力せよ。ファイルの編集・実装作業は行わない。

引数（フェーズ番号）: $ARGUMENTS

## 手順

1. プロジェクトルートの `STATE.md` を読む。
2. 「フェーズ一覧」から Phase $ARGUMENTS の名称・ステータス・受け入れ基準を抜き出す。
   - 該当フェーズが存在しない、または受け入れ基準が未記入の場合は、その旨を報告して停止する。文面を推測で組み立ててはならない（受け入れ基準は着手前に STATE.md へ事前記入するのが規約）。
   - 該当フェーズが既に完了（[x]）の場合は、/goal 文面を生成せず、再実行の要否（なぜ再実行が必要か／不要か）だけを報告して停止する。
3. 次の形式で /goal 文面を1行で組み立てる（`<受け入れ基準>` には STATE.md の記載を要約せず原文のまま埋め込む）:

   ```
   /goal STATE.md の Phase <番号>「<フェーズ名>」の受け入れ基準（<受け入れ基準>）を verifier サブエージェントが passed: true と判定するまで。5ターンで停止
   ```

4. 組み立てた文面をコードブロックで出力し、「この文面をコピーして実行してください」と案内する。

## 注意（この仕様の根拠）

- カスタムコマンドからビルトインの /goal を直接起動する仕組みは Claude Code に存在しない（Tools Reference に該当ツールなし）。そのため本コマンドは**コピペ用文面の出力まで**を行う。
- /goal のターン上限は条件文に停止句を含める方式（公式ドキュメント: code.claude.com/docs/en/goal.md）。推奨上限 5 を固定で含める。
- /goal 実行中も CLAUDE.md §7 の規約（判断の verifier 一本化・Stopフック・STATE.md 更新・検証履歴）はすべて適用される。
